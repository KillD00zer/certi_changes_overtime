# منظومة رصد التغيرات المكانية والإنشائية عبر الزمن (Spatial Changes Over Time)
### Dakahlia Utility Data Center (DUDC) - مركز معلومات شبكات المرافق

منظومة متكاملة وعالية الدقة لرصد وتوثيق التغيرات المكانية والإنشائية لأي قطعة أرض على مدار السنوات المتعاقبة، بناءً على ملف الرفع المساحي وتاريخ بداية الرصد المحدد.

---

## 🌟 الميزات الرئيسية (Key Features)
1. **محرك الأقمار الصناعية الافتراضي: Google Maps Satellite Engine**:
   - سحب بلاطات الأقمار الصناعية عالية الدقة مباشرة من خوادم **Google Maps** الرسمية (`mt0-3.google.com`).
   - تنزيل البلاطات بالتوازي السريع مع رسم حدود القطعة بدقة فائقة وإضافة شعار Google Maps وتاريخ وسنة الالتقاط وبوصلة الشمال.
   - يدعم التبديل السلس بين خوادم Google Maps وأرشيف Esri Wayback بضغطة زر واحدة.

2. **التكامل الفوري مع Google Earth Pro**:
   - زر **🌍 فتح في Google Earth (.kml)**: بنقرة واحدة يتم تصدير مضلع الأرض بنسق KML وتشغيل Google Earth Pro للتحليق المباشر فوق قطعة الأرض.
   - إمكانية استخدام شريط التغيرات الزمني (Historical Imagery Slider) في Google Earth Pro، مع دعم **لصق لقطات الشاشة مباشرة (Ctrl+V)** داخل المنظومة لكل سنة لتظهر تلقائياً في التقرير الرسمي!


3. **تقرير Word رسمي شامل (.docx)**:
   - غلاف رسمي ببيانات المواطن وموقع الأرض والمساحة المحسوبة وجدول إحداثيات أركان الموقع بدقة 8 أرقام عشرية.
   - بطاقات سنوية متتالية تحتوي على صورة القمر الصناعي عالية الدقة.
   - صندوق ملاحظات فحص ومعاينة ميدانية تحت كل سنة:
     * يتيح كتابة الملاحظات مسبقاً من خلال لوحة التحكم بالمتصفح.
     * أو يترك سطوراً منقطة وقائمة مرجعية (أرض فضاء / تشوين / قواعد وسملات / دور أرضي / تعلية) للكتابة اليدوية والاعتماد.
   - جدول اعتماد وتوقيعات اللجنة الفنية وإدارة المتغيرات المكانية.

4. **واجهة مستخدم عصرية وسريعة (Modern Dark-Mode Dashboard)**:
   - تعمل محلياً داخل المتصفح عبر خادم `app_server.py`.
   - تجربة فورية بنقرة واحدة لتحميل ملف العينة المدمج (`طناح - المنصورة`).
   - إمكانية استعراض وتغيير مجلد الحفظ مباشرة وفتحه في Windows Explorer.

## 🚀 طريقة التشغيل (How to Run)

### الطريقة الأولى: بنقرة واحدة (One-Click)
1. افتح المجلد: `d:\Work\GIS_tools\certi_changes_overtime`
2. اضغط مرتين على الملف: `Run_Changes_Overtime.bat`
3. سيتم تشغيل الخادم وفتح المتصفح تلقائياً على الرابط: `http://127.0.0.1:8768`

### الطريقة الثانية: من سطر الأوامر (Command Line)
```bash
cd d:\Work\GIS_tools\certi_changes_overtime\src
python app_server.py
```

## 📋 خطوات الاستخدام السريعة:
1. اضغط زر **⚡ تجربة فورية: تحميل ملف العينة (طناح)**، أو اسحب أي ملف `.csv` أو `.xlsx`.
2. حدد أو عدل **تاريخ بداية الرصد** (مثلاً: `2018-05-20`).
3. تنقل بين السنوات عبر شريط التبويبات الزمني، وشاهد صور القمر الصناعي التاريخية تباعاً.
4. أضف أي ملاحظات ميدانية لكل سنة، أو اختر من الأزرار السريعة.
5. اختر أسماء أعضاء اللجنة الفنية واضغط **📄 إصدار تقرير التغيرات المكانية الشامل (.docx)**.
6. اضغط **📁 فتح المجلد** لتجد مجلد المواطن يحتوي على التقرير الرسمي والصور السنوية وملف الرفع الأصلي.
